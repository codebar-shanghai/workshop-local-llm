# Workshop: How to Run a Language Model on Your Computer

This repo contains notes and slides for the workshop.

The slides are written in Markdown and presented with [reveal.js](https://revealjs.com/). To use the slides you'll need an HTTP server, for example `python3 -m http.server 5003`, and then visit `http://localhost:5003` in a browser.

The notes are written in [LaTeX](https://en.wikipedia.org/wiki/LaTeX) and built with the [build-pdf](./.github/workflows/build-pdf.yml) workflow. You can find the PDFs from the [release](https://github.com/codebar-shanghai/workshop-local-llm/releases) page.
