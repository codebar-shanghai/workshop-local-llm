# Contributing

Feel free to improve the notes. We are not LLM experts, so the notes may contain inaccurate information or mistakes.

Most modern editors provide syntax highlighting for LaTeX. You can skip building the PDFs on your computer, because a workflow runs for every pull request.

If you want to build the PDFs locally, please check how to install the required LaTeX packages for your system. You may also need to install the font [Noto Sans Mono](https://fonts.google.com/noto/specimen/Noto+Sans+Mono).
